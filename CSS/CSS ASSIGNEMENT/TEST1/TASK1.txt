14.Explain Flexbox.What are:Flex Container,Flex Item,Main Axis,Cross Axis?
ans)Flexbox: A CSS layout used to arrange and align items easily.
Flex Container: The parent element that controls the layout.
Flex Item: The child elements inside the flex container.
Main Axis: The main direction in which items are arranged (default: left to right).
Cross Axis: The direction perpendicular to the main axis (default: top to bottom).
