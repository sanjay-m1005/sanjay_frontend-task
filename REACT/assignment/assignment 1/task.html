1. **What is React?** React is a JavaScript library used to build user interfaces (UI). Mainly websites/web apps-la interactive UI create panna use pannuvom. 2. **Is React a library or framework?** React is a **JavaScript library**, framework illa. UI part-ku mainly focus pannum. 3. **What is a Component?** Component na UI-oda oru small reusable part. Example: `Navbar`, `Button`, `Card` etc. 4. **Why are Components important?** Components use pannina code-a reusable and organized-aa maintain panna mudiyum. Same component-a multiple places-la use pannalam. 5. **What is JSX?** JSX means **JavaScript XML**. JavaScript-kulla HTML maari code write panna allow pannum. 6. **What is Virtual DOM?** Virtual DOM is Real DOM-oda lightweight copy/memory representation. React changes-a first Virtual DOM-la compare pannum. 7. **What is Real DOM?** Real DOM is browser-la actual webpage structure. UI-la changes panna browser Real DOM-a update pannum. 8. **What is Reconciliation?** Reconciliation na old Virtual DOM-um new Virtual DOM-um compare pannura process. Difference irukkura parts mattum Real DOM-la update pannum.
